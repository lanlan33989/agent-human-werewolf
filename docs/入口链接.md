## 4. 并行加东西的规矩（一句话版）

后端加字段/接口 → 先在 `docs/contract.md` 贴真实样例 → 前端照样例在
`demo_scenes.js` 加场景（画廊立刻能看）→ 后端把样例同步进 `frontend/mock/` →
真后端就绪后前端只换数据源。详见
[docs/前端界面清单.md §3](https://github.com/lanlan33989/agent-human-werewolf/blob/main/docs/%E5%89%8D%E7%AB%AF%E7%95%8C%E9%9D%A2%E6%B8%85%E5%8D%95.md)。
