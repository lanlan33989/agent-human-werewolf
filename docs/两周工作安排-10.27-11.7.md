## 二、阶段①：并行迭代（10/27–11/1）

### 2.1 宁晰琳 —— 提示词工程：纯 AI 对局迭代（主线）

| 项     | 内容                                                                                        |
| ----- | ----------------------------------------------------------------------------------------- |
| 做法    | 在实验台上用纯 AI 对局快照迭代，可反复跑、可回滚                                                                |
| 输入    | 杨家彦的语料候选池（30–50 条，带标签已脱敏）                                                                 |
| 交接    | 与郑锦川对齐一次提示词接口与上下文格式（**郑锦川主导**），之后不依赖主产品。〔10-27 微调〕对齐会照《工作台详细说明》过一遍即可，半小时内完成             |
| 本周目标  | 每改一版提示词，都用**同样 5 个测试场景**重跑一遍做检查（被怀疑时的自辩、第二轮投票、狼人被同伴出卖、预言家报验、遗言）；本周结束时，最后一版要在这 5 个场景里都不出问题 |
| ⚠️ 补充 | 周内先用实验台固定场景跑一遍**存基线**（可重放），之后每版对比才有参照。〔10-27 微调〕实验台已能**每局自动留档且自带版本标记**，基线与后续每版都记下留档编号即可，无需手动整理 |

### 2.2 杨家彦 —— 语料库（交付给宁晰琳）

| 项    | 内容                                                          |
| ----- | ----------------------------------------------------------- |
| 交付给谁 | **宁晰琳**——她把语料用进提示词迭代                                        |
| 交付内容 | ① 语料库清单（多少条、来源、格式）；② 候选样例池 30–50 条，每条带简单标签（身份/轮次/功能），脱敏在源头做 |
| 说明   | 以上条数和格式是**建议值**，具体挑哪些、按什么格式，**杨家彦和宁晰琳根据实际情况进行把控**           |
| 〔10-27 微调〕 | 语料接入方式以**写进提示词文本**为主（示例句、结构规则）；预留的"示例自动注入"机制暂未启用，本周不必等它 |

### 2.3 郑锦川 —— 后端：状态推进无异常

| 项  | 内容                              |
| -- | ------------------------------- |
| 目标 | 交一版状态推进无误的主产品（本轮次、投票、结算、出局全部正确） |
| 每日自检 | 配套的自动化检查应全绿跑通。〔10-27 微调〕现有 6 处**历史遗留失败**（与最近改动无关，清单在后端说明文档），建议本轮顺手清掉，避免联调期误判 |
| 边界 | 尽量只修bug，不大改结构                   |

### 2.4 黄子凡 —— 前端：好看、按钮/图标够大、AI 表情

| 项  | 内容                                                                                                    |
| -- | ----------------------------------------------------------------------------------------------------- |
| 目标 | 界面观感（好看，需要相汇报评委展示，重要）、操作可达性（按钮/图标够大，人类玩家在需要操作的时候可以直接伸手按到在桌子中央的手机按钮）、AI 发言带**动态表情**（表情会动即可，不要求和发言内容对应） |
| 安排 | 11/2 起不再加新的界面功能，之后专心配合联调                                                                              |
| 〔10-27 微调〕 | 本周全程可用**假数据**开发界面（配套的假数据服务已就位），不需要等后端；表情动画的挂点位置见前端说明文档                                           |
